=========================================
COMMANDES DU PROJET
=========================================

= Executer depuis la racine du projet
C:\wamp64\www\lolissr

= Afficher toutes les commandes disponibles et leurs descriptions
composer run-script --list


=========================================
DEVELOPPEMENT
=========================================

= Installer les dependances
composer install

= Compiler CSS / JavaScript et actualiser leurs versions
composer assets:build

= Diagnostic de configuration, services et assets
composer doctor


=========================================
DX
=========================================

= Appliquer le formatage PHP / JavaScript / CSS
composer dx

= Verifier le formatage sans modifier les fichiers
composer dx:check


=========================================
GIT
=========================================

= Compiler les assets, creer un commit APP_NAME / APP_VERSION et pousser sur origin/master
composer git:publish

= Annuler les modifications locales et supprimer les fichiers non suivis
= Execute git reset --hard HEAD et git clean -fd
composer git:reset


=========================================
TESTS
=========================================

!! Identifiants HTTP_TEST_USERNAME / HTTP_TEST_PASSWORD dans .env pour les tests HTTP

= Tous les controles
= check + (Tests navigateur Edge, schéma MySQL, isolation des comptes via HTTP, dépendances de production et cache HTTP des assets)
composer check:all

= Analyse PHP + tests HTTP / SPA + regressions (mangas, recherche, assets, etc.)
composer check






=========================================
IMAGES
=========================================

= Uploads par formulaire et scripts : empreintes actualisees automatiquement

= Optimiser les profils, migrer leurs extensions et actualiser les manifestes
composer images:build

= Apres ajout, remplacement ou suppression MANUELLE d'une image de profil
= Actualise la version globale et les empreintes individuelles de toutes les images
composer images:manifest

= Apres remplacement MANUEL d'autres images, variantes .grid comprises
= Reconstruction requise meme si la taille et les dates sont conservees
composer images:fingerprints

= Auditer les miniatures sans modification
composer images:optimize

= Optimiser avec sauvegarde et generer les variantes .grid
composer images:optimize -- --apply

= Generer uniquement les variantes .grid de 600 px
composer images:variants -- --apply

= Sauvegardes des originaux
storage/backups/images/


=========================================
MANGA
=========================================

= Windows : sorties a 09:00, recommandations a 09:15 et ouverture de session
= PC allume, Apache/MySQL disponibles ; aucune commande quotidienne necessaire

= Actualiser manuellement les tomes a venir
composer manga:sync

= Actualiser manuellement les recommandations du compte local
= Remplacer 1 par l'identifiant du compte concerne
composer manga:recommendations -- 1

= Apres modification manuelle du catalogue JSON : republier sa revision sans reseau
composer manga:catalog-revision

= Installer/reinstaller la tache Windows des sorties
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Manga/install-schedule.ps1

= Installer/reinstaller la tache Windows des recommandations pour le compte 1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Manga/install-recommendations-schedule.ps1 -OwnerId 1

= Sur un autre serveur : planifier les deux commandes d'actualisation

= Journaux des actualisations
storage/logs/manga-releases-sync.log
storage/logs/manga-recommendations-sync.log

= Correspondances des editions
Config/settings/manga-releases.php


=========================================
BASE DE DONNEES
=========================================

= Sauvegarder la base du .env dans storage/backups/database/
= MYSQLDUMP_PATH permet de choisir mysqldump si necessaire
composer backup

= Creer un fichier SQL de migration, puis l'editer
composer db:migration -- ajout-table

= Appliquer les migrations apres sauvegarde
composer db:migrate

= Voir l'etat des migrations sans modification
composer db:migrate:status

= Ne pas executer le meme SQL dans /sql ni modifier une migration deja appliquee

= Enregistrer une migration deja appliquee, apres verification manuelle
composer db:migrate:baseline -- YYYY-MM-DD-NN-description.sql

= Une migration failed/running demande verification et reparation avant baseline

= Verifier le schema avec des fixtures temporaires
composer db:check

= Verifier l'isolation des comptes et sessions
composer users:check

= Auditer les index redondants sans modification
composer db:deduplicate-indexes

= Supprimer les index identifies comme redondants
composer db:deduplicate-indexes -- --apply

= Auditer les recompenses XP sans modification
composer xp:backfill -- USER_ID

= Attribuer uniquement les recompenses XP manquantes
composer xp:backfill -- USER_ID --apply


=========================================
MAINTENANCE
=========================================

= Vider logs / cache / sessions et regenerer l'autoload
composer dev:reset

= Vider uniquement les logs
composer logs:clear

= Vider uniquement le cache
composer cache:clear

= Vider les sessions et deconnecter les utilisateurs
composer sessions:clear

= Sur le serveur : nettoyer les anciens bundles selon la retention de sept jours
= Ne pas supprimer les chunks en fonction du seul manifeste actif
composer js:prune


=========================================
MESURES
=========================================

= Mesurer la recherche, les listes et les pages sans modification de la base
= Remplacer 1 par le compte ; le cache applicatif peut etre actualise
composer search:profile -- 1 Berserk --limit=5 --lists --pages=1,20

= Mesurer cinq passages HTTP
= Rapport : tests/Http/reports/lolissr-http-report.html
composer http:profile

OUTILS OCCASIONNELS
=========================================

composer install --no-dev --optimize-autoloader

composer dump-autoload

composer validate

= Synchroniser le lock sans changer les versions
composer update --lock

composer css:build

= Compiler uniquement le JavaScript
composer js:build

= Installer esbuild
composer js:install






=========================================
AVANT LIVRAISON
=========================================

= Compiler les assets, verifier le formatage et lancer tous les controles
= Necessite Apache/MySQL/Edge, dependances de developpement et identifiants HTTP de test dans .env
composer preflight






= Generer une archive avec images, assets actifs et dependances de production
composer release:zip

= Mise a jour en conservant les images du serveur
composer release:zip -- --without-images

= Archives dans releases/ ; nom defini par APP_NAME / APP_VERSION
= Envoyer avec FileZilla ; la base est livree separement
= Premiere installation : copier .env.example vers .env sur le serveur et renseigner MySQL / APP_BASE_URI
= En production : APP_ENV=production et APP_DEBUG=false

= Apres installation ou modification de configuration sur le serveur cible : compiler le bootstrap
composer bootstrap:cache

= Desactiver le cache de configuration et de routes
composer bootstrap:clear
